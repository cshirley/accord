# Playbooks

* [Local development setup](/playbooks/local-development-setup.md) - Register this checkout with Pi, link assets, verify install, edit-test loop.
* [Run a work item](/playbooks/run-a-work-item.md) - Ticket or free text → spec/plan → implementation → finish → PR, in Pi or headless.
* [Answer decisions](/playbooks/answer-decisions.md) - Resolve `needs_input` / `stuck` questions and resume.
* [Unblock a task](/playbooks/unblock-a-task.md) - Break or reset a stuck test/review loop with `block` / `unblock`.
* [Add an agent](/playbooks/add-an-agent.md) - New phase or review agent end-to-end.
* [Add a provider](/playbooks/add-a-provider.md) - Bundled or project-local tracker/enrichment.
* [Add a language](/playbooks/add-a-language.md) - Stack detection + lang profile.
* [Verify a change](/playbooks/verify-a-change.md) - Run the repo's verification suite before commit/PR.
* [Adopt the autopipeline](/playbooks/adopt-autopipeline.md) - Jira ticket → PR in a consumer repo via GitHub Actions.
